# Changelog

## 0.1.0

- Initial release.
- Activating Anima Echo resets all skill cooldowns, including Sacrifice and Blade Slice quickstrike charges.
- With Anima Echo selected, Sacrifice grants 3 Convictions instead of 2.
- Convictions earned during the Echo Litany are stored and granted when it ends.
- Updated Anima Echo and Sacrifice descriptions in all 12 game languages.
